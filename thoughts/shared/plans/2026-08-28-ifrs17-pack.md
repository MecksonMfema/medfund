## What We're NOT Doing

Explicit non-goals for this plan:

- **Additional market-data adapters beyond ZW (RBZ) + ZA (SARB).** US Fed / UK BoE / KES CBK come as follow-up per-tenant demand.
- **Cross-language docker-compose IT.** Deferred to a Phase-15-integration follow-up (2 golden-path specs — LRC/LIC + Insurance Revenue) per parent-plan I* Success Criteria.
- **Full IFRS 17 disclosure suite beyond LRC/LIC + Insurance Revenue + Service Result.** Sensitivity analysis, reconciliation of insurance service result, confidence-level *distribution* disclosure (beyond point-estimate) — follow-ups.
- **Portfolio deactivation lifecycle with open contracts.** Handling for `ifrs17_portfolio.is_active=false` when contracts are still LRC-carrying — follow-up.
- **Bulk CSV upload for basis + yield curve + expense config beyond per-row entry + optional CSV.** Advanced bulk import UX is a follow-up.
- **`RuleCategory.IFRS17_COVERAGE_UNITS` as separate category** — I9 bundled coverage-unit selection into `IFRS17_MODEL` rule.
- **Retroactive yield curve corrections.** If RBZ republishes a past date's curve with a correction, historic `locked_in_yield_curve_snapshot` values are NOT retroactively updated (per IFRS 17.44 lock-in mechanics). Deferred: an admin-only "recompute historic locked-in for cohort X" surface.
- **Live dashboards (Elixir) integration.** `medfund.ifrs17.material-event` topic is the natural feed source but Elixir consumer is a follow-up plan.
- **Cross-tenant analytics feed to `/platform/analytics`.** IFRS 17 metrics rollup for super-admin dashboard is a follow-up.
- **Angular waterfall chart animation polish.** Ships with animations off per Phase 14 A14 precedent.
- **Retention class configurability per tenant.** I28 hardcoded split: STATUTORY_7Y for IFRS17_* + REGULATORY family; OPERATIONAL_90D for all others. Tenant-configurable retention deferred.
- **Reverse migration (STATUTORY_7Y → OPERATIONAL_90D reclassification).** Once a report_job is classified statutory at insert, it stays that way for its 7-year retention.

## Implementation Approach

**Rollout order**: rename infrastructure first (§1 dual-write Phase A) so Phase 14 keeps working; then schema (§2-§8) and admin CRUD to unlock every tenant admin surface; then rules-engine (§9) to enable the model-selection pipeline; then compute infrastructure (§10 MinIO helper); then Python compute (§11-§16 progressively per model + method); then Java aggregator + report controller (§17-§19); then notification dispatcher (§20); then Angular UI (§21); then rename cutover (§22 Phase B) + cleanup (§23 Phase C); then market-data-service (§24 — can be built earlier but its consumers depend on §2 yield curve tables); finally e2e + perf (§25).

**Cross-phase invariants** all uphold:

1. Every wrapped IFRS 17 report endpoint carries `@RequiresReport(ReportKey.X)` + `SecurityEventPublisher.publishDataAccess` on export (parent-plan invariants #2 + #3).
2. All amount arithmetic uses `BigDecimal`; FX conversion via existing `FxConverter` + `public.exchange_rates` V112 machinery. G8 middle-ground FX policy: historical for movements, closing for balances, no explicit translation adjustment row.
3. Every entity mutation emits an `AuditEvent` via existing Kafka path per Rule 8; every export emits a `SecurityEvent` per Rule 9. Both use `AuditActor` helper (never inline JWT extraction).
4. Kafka consumer ack via `.doOnSuccess` per `bug_reactor_kafka_ack_swallow`.
5. Tenant-scoped R2DBC queries only; never `public.` prefix on tenant tables per `bug_public_prefix_silent_rollback`.
6. All new endpoints carry OpenAPI 3.1 annotations per Rule 7.
7. R2DBC entities leave `@Id UUID` null on insert when column has `DEFAULT gen_random_uuid()` per `bug_r2dbc_pre_populated_id_update_mode`.

**Kafka contracts** stay backwards-compatible during rename window: additive fields only; `schema_version: 1` on both new topics. Deploy order for §1 dual-write: ai-service consumer dual-subscribes BEFORE finance-service publisher dual-writes (avoid publish-into-void); finance-service result consumer dual-subscribes BEFORE ai-service result publisher dual-writes (avoid orphan results). §22 Phase B flips producer/consumer to new-only. §23 Phase C deletes old topics.

package com.medfund.finance.report.kafka;

@Slf4j
@Component
@RequiredArgsConstructor
public class ReportJobPublisher {

    public static final String TOPIC_NEW = "medfund.report.job-requested";
    public static final String TOPIC_LEGACY = "medfund.actuarial.job-requested"; // dual-write per I10 Phase A

    private final KafkaSender<String, String> kafkaSender;
    private final ObjectMapper objectMapper;

    public Mono<Void> publish(ReportJobRequestedEvent event) {
        // ... existing size guard (>800KB warn, >900KB MinIO fallback via I25 — deferred to §10)
        String key = event.jobId().toString();
        String payload = objectMapper.writeValueAsString(event);

        var newRec = new ProducerRecord<>(TOPIC_NEW, key, payload);
        var legacyRec = new ProducerRecord<>(TOPIC_LEGACY, key, payload);

        // Publish to both. Failure on either logs but does not abort — dual-write is best-effort
        // during the transition window per I10 Phase A.
        return Mono.zip(
                kafkaSender.send(Mono.just(SenderRecord.create(newRec, null))).next(),
                kafkaSender.send(Mono.just(SenderRecord.create(legacyRec, null))).next())
            .doOnSuccess(x -> log.debug("Published report_job {} to both topics", event.jobId()))
            .doOnError(e -> log.error("Dual-write partial failure for job {}: {}",
                event.jobId(), e.getMessage(), e))
            .then();
    }
}
```

        return repository.findById(event.jobId())
            .flatMap(job -> {
                // Rule 2 guard: verify tenant match per Phase 14 A15
                if (!job.getTenantId().equals(event.tenantId())) {
                    return Mono.error(new IllegalStateException(
                        "Cross-tenant event rejected: job.tenantId=" + job.getTenantId()
                            + " event.tenantId=" + event.tenantId()));

                if ("completed".equals(job.getStatus()) || "failed".equals(job.getStatus())) {
                    log.debug("Duplicate terminal event for job {} — skipping", event.jobId());
                    return Mono.empty();
                }
                job.setStatus(event.status());
                job.setResultJson(event.resultJson());
                job.setErrorMessage(event.errorMessage());
                job.setCompletedAt(Instant.now());
                return repository.save(job);
            })
            .then();

                                             UUID actorId, String actorEmail) {

        entity.setActorEmail(actorEmail);

                    /* correlationId */ UUID.randomUUID().toString(),
                    /* actorId    */  actorId,

    public void purgeStale() {
        Instant operationalCutoff = Instant.now().minus(OPERATIONAL_TTL);

```sql
-- Backfill: for cohorts with locked_in_at IS NULL, use the earliest policy issuance date
-- from any policy in the cohort as the snapshot date. Fetch historic curve from
-- tenant_yield_curve where effective_from <= earliest_issuance ORDER BY effective_from DESC LIMIT 1.
-- If no historic curve found, use current curve + set source='BACKFILL_FALLBACK' + emit warning.

WITH cohort_first_issuance AS (
    SELECT
        c.id AS cohort_id,
        COALESCE(
            (SELECT MIN(lp.issuance_date) FROM life_policies lp WHERE lp.cohort_id = c.id),
            (SELECT MIN(fp.issuance_date) FROM funeral_policies fp WHERE fp.cohort_id = c.id),
            (SELECT MIN(dp.issuance_date) FROM disability_policies dp WHERE dp.cohort_id = c.id),
            (SELECT MIN(tp.issuance_date) FROM travel_policies tp WHERE tp.cohort_id = c.id),
            (SELECT MIN(v.issuance_date) FROM vehicles v WHERE v.cohort_id = c.id),
            (SELECT MIN(p.issuance_date) FROM properties p WHERE p.cohort_id = c.id)
        ) AS earliest_issuance
    FROM ifrs17_cohort c
    WHERE c.locked_in_at IS NULL
),
curve_snapshot AS (
    SELECT
        cfi.cohort_id,
        cfi.earliest_issuance,
        jsonb_agg(jsonb_build_object('tenor_months', yc.tenor_months, 'spot_rate', yc.spot_rate))
            AS snapshot
    FROM cohort_first_issuance cfi
    LEFT JOIN public.tenant_yield_curve yc
        ON yc.currency = 'USD'  -- Default currency; per-currency snapshot done in application code
        AND yc.effective_from <= cfi.earliest_issuance
        AND (yc.effective_to IS NULL OR yc.effective_to > cfi.earliest_issuance)
    GROUP BY cfi.cohort_id, cfi.earliest_issuance
)
UPDATE ifrs17_cohort c
SET locked_in_yield_curve_snapshot = cs.snapshot,
    locked_in_at = cs.earliest_issuance
FROM curve_snapshot cs
WHERE c.id = cs.cohort_id AND cs.earliest_issuance IS NOT NULL;

-- Cohorts with no policies stay locked_in_at=NULL. First policy issuance triggers lock-in via
-- Ifrs17CohortLockInService at that point.
```

**Note**: This backfill covers the USD default case. Application-level backfill (a startup task at first run) handles per-currency snapshot properly reading the full curve shape.

@Slf4j
@Component
@RequiredArgsConstructor
public class MinIOPayloadStore {

    private final MinioClient client;

    @Value("${minio.bucket.report-payloads:medfund-report-payloads}")
    private String bucket;

    private static final int SIZE_WARN = 800 * 1024;
    private static final int SIZE_LIMIT = 900 * 1024;

    /**
     * If payload size exceeds SIZE_LIMIT, upload to MinIO and return the ref.
     * Otherwise return null (caller uses inline payload).
     *
     * @return "s3://medfund-report-payloads/{key}" or null if inline OK
     */
    public String maybeUploadInput(UUID jobId, UUID chunkId, byte[] payload) {
        int size = payload.length;
        if (size > SIZE_WARN && size <= SIZE_LIMIT) {
            log.warn("Payload for job {} chunk {} nearing limit ({}KB)", jobId, chunkId, size / 1024);
            return null;
        }
        if (size <= SIZE_LIMIT) {
            return null;
        }
        String key = jobId + "-" + chunkId + "-input.json";
        try {
            client.putObject(PutObjectArgs.builder()
                .bucket(bucket)
                .object(key)
                .stream(new ByteArrayInputStream(payload), size, -1)
                .contentType("application/json")
                .build());
            log.info("Uploaded oversize payload for job {} chunk {} → {}", jobId, chunkId, key);
            return "s3://" + bucket + "/" + key;
        } catch (Exception e) {
            throw new RuntimeException("MinIO upload failed for " + key, e);
        }
    }

    public byte[] download(String payloadRef) {
        String key = payloadRef.substring(("s3://" + bucket + "/").length());
        try (InputStream stream = client.getObject(GetObjectArgs.builder()
                .bucket(bucket)
                .object(key)
                .build())) {
            return stream.readAllBytes();
        } catch (Exception e) {
            throw new RuntimeException("MinIO download failed for " + key, e);
        }
    }

    public void delete(String payloadRef) {
        String key = payloadRef.substring(("s3://" + bucket + "/").length());
        try {
            client.removeObject(RemoveObjectArgs.builder().bucket(bucket).object(key).build());
        } catch (Exception e) {
            log.warn("MinIO delete failed for {}: {}", key, e.getMessage());
        }
    }
}

            access_key=os.environ["MINIO_ACCESS_KEY"],
            secret_key=os.environ["MINIO_SECRET_KEY"],
            secure=False,
        )

def maybe_upload_result(job_id: str, chunk_id: str, payload_bytes: bytes) -> str | None:
    """Upload result JSON to MinIO if oversize; return payload_ref or None if inline."""
    if len(payload_bytes) <= SIZE_LIMIT:
        return None
    key = f"{job_id}-{chunk_id}-result.json"
    try:
        _get_client().put_object(
            _bucket,
            key,
            BytesIO(payload_bytes),
            length=len(payload_bytes),
            content_type="application/json",
        )
        logger.info("Uploaded oversize result for job=%s chunk=%s → %s", job_id, chunk_id, key)
        return f"s3://{_bucket}/{key}"
    except S3Error as e:
        raise RuntimeError(f"MinIO upload failed for {key}: {e}") from e


def download(payload_ref: str) -> bytes:
    key = payload_ref[len(f"s3://{_bucket}/"):]
    response = _get_client().get_object(_bucket, key)
    try:
        return response.read()
    finally:
        response.close()
        response.release_conn()
```

# services/python/ai-service/app/ifrs17/paa.py
"""PAA (Premium Allocation Approach) LRC/LIC computation per IFRS 17.

Simplified per I15: skips discounting when coverage_duration ≤12mo AND
settlement_duration ≤12mo (IFRS 17.59). Applies to per-portfolio-cohort-currency chunk."""
from decimal import Decimal
from datetime import date
from typing import Optional
from .types import PaaChunkInput, ChunkResult, LrcMovement, LicMovement

DISCOUNT_SKIP_THRESHOLD_MONTHS = 12


def compute(input: PaaChunkInput) -> ChunkResult:
    """Compute LRC + LIC for a PAA-measured chunk."""
    coverage_duration_months = _months_between(
        input.earliest_coverage_start, input.latest_coverage_end)
    settlement_duration_months = _median_settlement_days(input.claim_history) // 30

    apply_discount = not (coverage_duration_months <= DISCOUNT_SKIP_THRESHOLD_MONTHS
                          and settlement_duration_months <= DISCOUNT_SKIP_THRESHOLD_MONTHS)

    # LRC = written − earned (per Phase 12 earning_schedule aggregation).
    lrc_movement = LrcMovement(
        opening=input.opening_lrc,
        new_business=input.new_business_written,
        cash_inflows=input.premiums_received,
        cash_outflows=Decimal(0),
        insurance_revenue=input.earned_in_period,
        insurance_service_expenses=Decimal(0),
        finance_expense_pl_portion=Decimal(0),
        finance_expense_oci_portion=Decimal(0),
        ra_release=Decimal(0),
        csm_release=Decimal(0),
        loss_component_recognized=input.loss_component_recognized,
        loss_component_released=input.loss_component_released,
        loss_component_reversal=Decimal(0),
        closing=input.opening_lrc + input.new_business_written + input.premiums_received
                - input.earned_in_period + input.loss_component_recognized
                - input.loss_component_released,
    )

    # LIC = incurred not yet paid + IBNR (from Phase-14 sub-job per I24) + RA.
    lic_movement = LicMovement(
        opening=input.opening_lic,
        new_incurred=input.claims_incurred_in_period,
        claims_paid=input.claims_paid_in_period,
        expenses_paid=input.expenses_paid,
        finance_expense_pl_portion=_pl_portion(apply_discount, input),
        finance_expense_oci_portion=_oci_portion(apply_discount, input),
        ra_change=input.ra_change,
        ra_release=input.ra_release,
        closing=input.opening_lic + input.claims_incurred_in_period
                - input.claims_paid_in_period + input.ra_change - input.ra_release,
    )

    return ChunkResult(
        job_id=input.job_id,
        portfolio_id=input.portfolio_id,
        cohort_id=input.cohort_id,
        currency=input.currency,
        model="PAA",
        lrc_movement=lrc_movement,
        lic_movement=lic_movement,
        discounting_applied=apply_discount,
        discounting_skip_reason=None if apply_discount else "IFRS_17_59_coverage_le_12mo",
        applied_rule_name=input.applied_rule_name,
        warnings=[],
    )


def _months_between(start: date, end: date) -> int:
    return (end.year - start.year) * 12 + (end.month - start.month)


def _median_settlement_days(claim_history: list) -> int:
    if not claim_history:
        return 0
    # median of (paid_at - service_date).days
    intervals = sorted((c.paid_at - c.service_date).days for c in claim_history if c.paid_at)
    return intervals[len(intervals) // 2] if intervals else 0


def _pl_portion(apply_discount: bool, input) -> Decimal:
    if not apply_discount:
        return Decimal(0)
    # Systematic allocation: interest unwind at locked-in rate.
    # Full formula in §12 GMM shared helper (imported here).
    return input.locked_in_discount_rate * input.opening_lic
        if input.finance_expense_presentation == "PL_ONLY" else Decimal(0)


def _oci_portion(apply_discount: bool, input) -> Decimal:
    if not apply_discount or input.finance_expense_presentation == "PL_ONLY":
        return Decimal(0)
    # OCI residual: current rate unwind − locked-in rate unwind
    return (input.current_discount_rate - input.locked_in_discount_rate) * input.opening_lic
```

"""Yield curve interpolation for GMM/VFA discounting per I5 + I18."""
from typing import Dict, List, Tuple
from decimal import Decimal


def interpolate_spot_rate(curve_snapshot: List[Dict[str, float]], tenor_months: int) -> Decimal:
    """Linear interpolation between tenors; flat extrapolation beyond longest."""
    if not curve_snapshot:
        raise ValueError("Empty curve snapshot")
    sorted_curve = sorted(curve_snapshot, key=lambda p: p["tenor_months"])
    if tenor_months <= sorted_curve[0]["tenor_months"]:
        return Decimal(str(sorted_curve[0]["spot_rate"]))
    if tenor_months >= sorted_curve[-1]["tenor_months"]:
        return Decimal(str(sorted_curve[-1]["spot_rate"]))
    for i in range(len(sorted_curve) - 1):
        lo, hi = sorted_curve[i], sorted_curve[i + 1]
        if lo["tenor_months"] <= tenor_months <= hi["tenor_months"]:
            weight = (tenor_months - lo["tenor_months"]) / (hi["tenor_months"] - lo["tenor_months"])
            return Decimal(str(lo["spot_rate"] + weight * (hi["spot_rate"] - lo["spot_rate"])))
    raise ValueError(f"Curve interpolation failed for tenor={tenor_months}")


def discount_factor(spot_rate: Decimal, months_ahead: int) -> Decimal:
    """v^t = 1/(1+r)^(t/12)."""
    from decimal import getcontext
    getcontext().prec = 20
    return Decimal(1) / (Decimal(1) + spot_rate) ** (Decimal(months_ahead) / Decimal(12))
```

"""Coverage unit computation per I9 (bundled into IFRS17_MODEL rule).

Patterns: TIME | SUM_INSURED_TIME | SUM_AT_RISK_TIME | CLAIM_FREQUENCY_TIME."""
from decimal import Decimal
from typing import Callable

_PATTERN_HANDLERS: dict[str, Callable] = {}


def register(pattern: str):
    def deco(fn):
        _PATTERN_HANDLERS[pattern] = fn
        return fn
    return deco


@register("TIME")
def _time(input) -> Decimal:
    return Decimal(input.periods_in_scope)


@register("SUM_INSURED_TIME")
def _sum_insured_time(input) -> Decimal:
    return sum(
        Decimal(p.sum_insured) * Decimal(p.months_in_period) for p in input.policies_in_scope
    )


@register("SUM_AT_RISK_TIME")
def _sum_at_risk_time(input) -> Decimal:
    return sum(
        (Decimal(p.sum_insured) - Decimal(p.reserve_balance)) * Decimal(p.months_in_period)
        for p in input.policies_in_scope
    )


@register("CLAIM_FREQUENCY_TIME")
def _claim_freq_time(input) -> Decimal:
    return sum(
        Decimal(p.expected_claim_frequency) * Decimal(p.months_in_period)
        for p in input.policies_in_scope
    )


def compute(pattern: str, input) -> Decimal:
    if pattern not in _PATTERN_HANDLERS:
        raise ValueError(f"Unknown coverage_unit_pattern: {pattern}")
    return _PATTERN_HANDLERS[pattern](input)
```

#### 2. CSM roll-forward

**File**: `services/python/ai-service/app/ifrs17/csm.py` (new)

```python
"""CSM (Contractual Service Margin) roll-forward per IFRS 17.44.

CSM(t) = CSM(t-1) × (1 + locked_in_rate)^(1/12)  -- interest accretion
       + experience adjustments (per IFRS 17.B96)
       - CSM release (coverage_units_delivered / total_coverage_units_remaining) × CSM(t-1)

When CSM would go negative → loss component; §15 handles the transition."""
from decimal import Decimal
from .discount_curve import interpolate_spot_rate
from . import coverage_units


def roll_forward(
    opening_csm: Decimal,
    opening_curve_snapshot: list,
    experience_adjustment: Decimal,
    coverage_units_delivered_this_period: Decimal,
    coverage_units_remaining_before: Decimal,
    coverage_unit_pattern: str,
) -> tuple[Decimal, Decimal, bool]:
    """Returns (closing_csm, csm_released, went_negative)."""

    # Step 1: interest accretion at locked-in rate.
    rate = interpolate_spot_rate(opening_curve_snapshot, tenor_months=1)
    accreted = opening_csm * ((Decimal(1) + rate) ** (Decimal(1) / Decimal(12)))

    # Step 2: experience adjustments (per IFRS 17.B96).
    after_experience = accreted + experience_adjustment

    # Step 3: release proportional to coverage units delivered.
    if coverage_units_remaining_before > 0:
        release_fraction = coverage_units_delivered_this_period / coverage_units_remaining_before
    else:
        release_fraction = Decimal(0)
    csm_released = after_experience * release_fraction
    closing = after_experience - csm_released

    went_negative = closing < 0
    if went_negative:
        # Cap at zero; the negative delta becomes loss component (per §15).
        csm_released += closing  # reduce release by the negative amount
        closing = Decimal(0)

    return closing, csm_released, went_negative
```

from decimal import Decimal
from typing import Tuple, Optional


def test_onerous(
    projected_fcf: Decimal,
    premium_received: Decimal,
    remaining_csm: Decimal,
    current_cohort_type: str,
) -> Tuple[bool, str, Optional[Decimal]]:
    """
    Returns (is_now_onerous, transition_reason, loss_component_amount).

    Per IFRS 17.19: reassess whether group is onerous by determining if
    fulfilment cash flows exceed the carrying amount of CSM.

    fcf_exceeds_available = projected_fcf > (premium_received + remaining_csm)

    if fcf_exceeds_available and current_cohort_type != "ONEROUS":
        loss_component = projected_fcf - (premium_received + remaining_csm)

    return current_cohort_type == "ONEROUS", "NO_CHANGE", None

@Slf4j
@Service
@RequiredArgsConstructor
public class Ifrs17JobService {

    private final ReportJobRepository jobRepository;
    private final ReportJobChunkRepository chunkRepository;
    private final Ifrs17ShapingService shapingService;
    private final ReportJobPublisher publisher;
    private final MinIOPayloadStore minioStore;
    private final TenantRuleEngine ruleEngine;  // fires IFRS17_MODEL per portfolio

    public Mono<JobSubmissionResponse> submit(
            ReportKey key, Ifrs17ReportRequest request,
            UUID tenantId, UUID actorId, String actorEmail) {

        // Compute params-hash for idempotency dedup (partial UNIQUE index per Phase 14 A9).
        String paramsHash = computeParamsHash(tenantId, key, request);

        // Check for in-flight duplicate.
        return jobRepository.findInFlightByParamsHash(tenantId, paramsHash)
            .switchIfEmpty(Mono.defer(() -> insertParent(key, tenantId, request, paramsHash, actorId, actorEmail)
                .flatMap(parent -> shapingService.shapeChunks(parent, request)
                    .flatMap(chunkPayload -> insertAndPublishChunk(parent, chunkPayload))
                    .then(Mono.just(parent)))))
            .map(job -> new JobSubmissionResponse(job.getId(), job.getStatus(), countChunks(job.getId())));
    }

    private Mono<ReportJob> insertParent(ReportKey key, UUID tenantId, Ifrs17ReportRequest request,
                                          String paramsHash, UUID actorId, String actorEmail) {
        ReportJob parent = new ReportJob();
        // NOTE: leave id null per bug_r2dbc_pre_populated_id_update_mode
        parent.setTenantId(tenantId);
        parent.setReportKey(key.name());
        parent.setStatus("requested");
        parent.setParamsJson(toJson(request));
        parent.setParamsHash(paramsHash);
        parent.setRequestedAt(Instant.now());
        parent.setRequestedBy(actorId);
        parent.setRequestedByEmail(actorEmail);
        parent.setRetentionClass(classifyRetention(key));  // STATUTORY_7Y for IFRS17_*
        return jobRepository.save(parent);
    }

    private Mono<Void> insertAndPublishChunk(ReportJob parent, Ifrs17ChunkPayload chunkPayload) {
        ReportJobChunk chunk = new ReportJobChunk();
        chunk.setParentJobId(parent.getId());
        chunk.setPortfolioId(chunkPayload.portfolioId());
        chunk.setCohortId(chunkPayload.cohortId());
        chunk.setCurrency(chunkPayload.currency());
        chunk.setStatus("requested");
        chunk.setParamsJson(chunkPayload.paramsJson());
        chunk.setRequestedAt(Instant.now());

        // Size check + MinIO fallback (I25).
        byte[] payloadBytes = chunkPayload.paramsJson().getBytes(StandardCharsets.UTF_8);
        String payloadRef = minioStore.maybeUploadInput(parent.getId(), UUID.randomUUID(), payloadBytes);
        if (payloadRef != null) {
            chunk.setParamsRef(payloadRef);
            chunk.setParamsJson(null);   // MinIO holds it
        }

        return chunkRepository.save(chunk)
            .flatMap(saved -> publisher.publish(
                ReportJobRequestedEvent.builder()
                    .jobId(saved.getId())
                    .tenantId(parent.getTenantId())
                    .parentJobId(parent.getId())
                    .reportKey(parent.getReportKey())
                    .params(chunkPayload.paramsMap())
                    .ifrs17Json(chunkPayload.ifrs17Json())
                    .payloadRef(payloadRef)
                    .requestedBy(parent.getRequestedBy())
                    .requestedByEmail(parent.getRequestedByEmail())
                    .build()));
    }

    static String classifyRetention(ReportKey key) {
        return key.family() == ReportFamily.REGULATORY ? "STATUTORY_7Y" : "OPERATIONAL_90D";
    }
}

private List<Ifrs17ChunkPayload> buildChunks(
        List<Portfolio> portfolios, Map<UUID, List<Cohort>> cohorts, Tuple8 data,
        Ifrs17ReportRequest request) {
    List<Ifrs17ChunkPayload> chunks = new ArrayList<>();
    for (Portfolio p : portfolios) {
        // Fire IFRS17_MODEL rule for this portfolio.
        IfrsPortfolioFact fact = new IfrsPortfolioFact(p.id(), p.insuranceLine(),
            /* cohortYear */ null, tenant.jurisdictionCode(), request.reportingCurrency(),
            p.name(), p.createdAt());
        ruleEngine.evaluateInGroup("IFRS17_MODEL", fact);
        String model = fact.getMeasurementModel();  // 'PAA' | 'GMM' | 'VFA'

        for (Cohort c : cohorts.getOrDefault(p.id(), List.of())) {
            for (String currency : currenciesForCohort(c)) {
                chunks.add(Ifrs17ChunkPayload.builder()
                    .portfolioId(p.id())
                    .cohortId(c.id())
                    .currency(currency)
                    .measurementModel(model)
                    .coverageUnitPattern(fact.getCoverageUnitPattern())
                    .variableFeePattern(fact.getVariableFeePattern())
                    .financeExpensePresentation(fact.getFinanceExpensePresentation())
                    .appliedRuleName(fact.getAppliedRuleName())
                    .openingLrc(resolveOpeningLrc(p.id(), c.id(), currency, data.seed))
                    .openingLic(resolveOpeningLic(p.id(), c.id(), currency, data.seed))
                    // ... FCF projection inputs, claim history, earning_schedule, etc.
                    .lockedInCurveSnapshot(c.lockedInYieldCurveSnapshot())
                    .build());
            }
        }
    }
    return chunks;
}

    return chunkRepository.findById(event.jobId())
        .flatMap(chunk -> {
            // Rule 2 guard: verify tenant match.
            if (!event.tenantId().equals(chunk.getTenantId())) {
                return Mono.error(new IllegalStateException(
                    "Cross-tenant event rejected"));
            }
            // Idempotency: skip terminal chunks (dual-consumption dedup).
            if ("completed".equals(chunk.getStatus()) || "failed".equals(chunk.getStatus())) {
                return Mono.empty();

            chunk.setStatus(event.status());
            chunk.setResultJson(event.resultJson());
            chunk.setResultRef(event.payloadRef());
            chunk.setErrorMessage(event.errorMessage());
            chunk.setCompletedAt(Instant.now());

                .then(checkAndAggregateParent(chunk.getParentJobId()));
        });
}

private Mono<Void> checkAndAggregateParent(UUID parentJobId) {
    return chunkRepository.findAllByParentJobId(parentJobId)
        .collectList()

Single consumer, single ack, no race. Plus an extra guard: if a parent row surfaces with a report_key starting `IFRS17_`, skip so the aggregator (not the consumer) owns the parent write path.
2. **Envelope shape stored as `Map<String, Object>` + serialized via ObjectMapper**, not as a typed DTO. Follows the actuarial `resultJson` precedent (finance-service `report_job.result_json` is JSONB — Java + Python + Angular all serialize/deserialize without a shared Java class). The plan §18 §1 sketched an `envelopeBuilder.aggregate(chunks)` helper — this is the same idea, inlined into `Ifrs17JobAggregator.buildEnvelope()`.
3. **Chunk lookup via `Ifrs17JobAggregator.findChunk()`**, not exposed on the chunk repository. Kept the aggregator as the source of truth for the chunk-routing decision so the consumer doesn't grow a direct dependency on `ReportJobChunkRepository`. ```go
package ifrs17

import (
    "context"
    "encoding/json"
    "fmt"
    "log"
    "time"

    "github.com/segmentio/kafka-go"
    "github.com/redis/go-redis/v9"
    "medfund/notification-service/internal/email"
    "medfund/notification-service/internal/webhook"
)

const topic = "medfund.ifrs17.material-event"

type Dispatcher struct {
    kafka        *kafka.Reader
    email        *email.Client
    webhook      *webhook.Client
    redis        *redis.Client
    tenancyClient *TenancyClient
}

type MaterialEvent struct {
    SchemaVersion int       `json:"schema_version"`
    TenantID      string    `json:"tenant_id"`
    PortfolioID   string    `json:"portfolio_id"`
    CohortID      string    `json:"cohort_id,omitempty"`
    EventType     string    `json:"event_type"`
    Severity      string    `json:"severity"`
    Message       string    `json:"message"`
    SourceRunID   string    `json:"source_run_id,omitempty"`
    OccurredAt    time.Time `json:"occurred_at"`
}

func (d *Dispatcher) Start(ctx context.Context) {
    for {
        msg, err := d.kafka.ReadMessage(ctx)
        if err != nil {
            log.Printf("ifrs17 dispatcher kafka read: %v", err)
            continue
        }
        var event MaterialEvent
        if err := json.Unmarshal(msg.Value, &event); err != nil {
            log.Printf("ifrs17 dispatcher unmarshal: %v", err)
            continue
        }
        if err := d.dispatch(ctx, event); err != nil {
            log.Printf("ifrs17 dispatcher failed for tenant %s event %s: %v",
                event.TenantID, event.EventType, err)
            // Do not commit offset — will retry on next poll.
            continue
        }
        if err := d.kafka.CommitMessages(ctx, msg); err != nil {
            log.Printf("ifrs17 dispatcher commit: %v", err)
        }
    }
}

func (d *Dispatcher) dispatch(ctx context.Context, event MaterialEvent) error {
    configs, err := d.tenancyClient.GetNotificationConfigs(ctx, event.TenantID, event.EventType)
    if err != nil {
        return fmt.Errorf("fetch configs: %w", err)
    }

    for _, cfg := range configs {
        // Throttle check.
        dedupKey := fmt.Sprintf("ifrs17:%s:%s:%dm", event.TenantID, event.EventType, cfg.ThrottleMinutes)
        set, err := d.redis.SetNX(ctx, dedupKey, "1", time.Duration(cfg.ThrottleMinutes)*time.Minute).Result()
        if err != nil || !set {
            log.Printf("throttled: tenant %s event %s", event.TenantID, event.EventType)
            continue
        }

        // Deliver.
        switch cfg.DeliveryMethod {
        case "EMAIL", "BOTH":
            if err := d.deliverEmail(ctx, cfg.Recipient, event); err != nil {
                log.Printf("email delivery failed: %v", err)
            }
        }
        switch cfg.DeliveryMethod {
        case "WEBHOOK", "BOTH":
            if err := d.deliverWebhook(ctx, cfg.Recipient, event); err != nil {
                log.Printf("webhook delivery failed: %v", err)
            }
        }
    }
    return nil
}

```go
package main

import (
    "context"
    "log"
    "os"
    "os/signal"
    "syscall"

    "github.com/gofiber/fiber/v2"
    "github.com/robfig/cron/v3"
    "medfund/market-data-service/internal/adapters"
    "medfund/market-data-service/internal/publisher"
)

func main() {
    app := fiber.New()
    app.Get("/health", func(c *fiber.Ctx) error {
        return c.JSON(fiber.Map{"status": "ok"})
    })

    kafkaPub := publisher.NewKafkaPublisher(os.Getenv("KAFKA_BOOTSTRAP"))
    tenancyClient := NewTenancyClient(os.Getenv("TENANCY_URL"))

    scheduler := cron.New()
    scheduler.AddFunc("0 6 * * *", func() {
        // Daily at 06:00 UTC — fetch curves for all enrolled tenants.
        configs, _ := tenancyClient.ListMarketDataConfigs(context.Background())
        for _, cfg := range configs {
            adapter := adapters.For(cfg.Source)
            if adapter == nil {
                log.Printf("no adapter for source=%s", cfg.Source)
                continue
            }
            curve, err := adapter.Fetch(context.Background(), cfg.Currency)
            if err != nil {
                log.Printf("fetch failed for tenant %s currency %s: %v",
                    cfg.TenantID, cfg.Currency, err)
                continue
            }
            if err := kafkaPub.Publish(cfg.TenantID, cfg.Currency, cfg.Source, curve); err != nil {
                log.Printf("publish failed: %v", err)
            }
        }
    })
    scheduler.Start()

    stop := make(chan os.Signal, 1)
    signal.Notify(stop, os.Interrupt, syscall.SIGTERM)
    go func() {
        if err := app.Listen(":3005"); err != nil {
            log.Fatal(err)
        }
    }()
    <-stop
    log.Println("shutting down")
}
```

## Performance Considerations

- **Server-side SQL only** — never `.collectList()` into memory before aggregating (parent-plan performance section).
- **Chunking** — per I14 fan-out by (portfolio, cohort, currency); Kafka partition count sets max parallelism. Set `medfund.report.job-requested` partition count to at least 8 for reasonable tenant scale.
- **Cross-service Java→Java** uses `CrossServiceCallHelper` custom-timeout arm (30s ceiling per Phase 14 F14-4); per-hop timeout + retry + fallback + envelope warnings.
- **IFRS 17 compute latency** target — PAA sub-second per chunk; GMM ≤5s per chunk; VFA ≤5s per chunk. p99 end-to-end for 20-portfolio tenant ≤60s.
- **Kafka payload sizes** — I25 MinIO fallback gated at 900KB (warn at 800KB). GMM long-horizon LIFE projections most likely to hit ceiling.
- **Angular polling** at 2s tick per Phase 14 §10; backoff to 5s after 30s.
- **XLSX generation** — POI streaming API (SXSSF) for exports >10k rows (existing pattern from creditors + actuarial).
- **Job-row retention** — I28 split: STATUTORY_7Y for IFRS17_* keys (bloats storage — accept per compliance requirement); OPERATIONAL_90D for actuarial (Phase 14 default).
- **CSM roll-forward compute** — projection horizon capped at `_MAX_HORIZON_MONTHS = 480` (40 years) for LIFE; longer contracts truncated at horizon with warning per envelope.
- **Yield curve interpolation** — linear + flat extrapolation; cached per (currency, effective_from) at compute-time to avoid repeat lookups.
- **Loss component matview refresh** — CONCURRENTLY at end of each report run; unique index on `(cohort_id, currency)` required per Postgres concurrent-refresh rules.

That coupling would fight the existing per-tenor row model (yield curves are many rows per currency, market-data-config is one row per currency). Landed as a peer sub-tab `market-data-tab.component.ts` sitting alongside Yield Curves — same Phase 2/7/19 grouping deviation. Users manage curves and enrolments on adjacent tabs; a Yield Curves refresh after the daemon runs shows the auto-inserted rows with an RBZ_AUTO / SARB_AUTO badge.
6. **`upsertAutoFetched` preserves ADMIN / BACKFILL_FALLBACK rows.** The plan sketch said "consumer upserts `tenant_yield_curve` — auto-fetched rows written with `source='RBZ_AUTO'` or `'SARB_AUTO'`" but didn't spell out precedence when an admin has manually seeded a row. Landed a precedence rule inside `TenantYieldCurveService.upsertAutoFetched`: any existing row with `source IN ('ADMIN','BACKFILL_FALLBACK')` at the same (currency, tenor, effective_from) tuple is left untouched — admin intent + backfill fallback both trump auto-fetch. Auto-fetched rows only overwrite prior AUTO rows on the same tuple; a truly new tuple inserts fresh. This makes the daemon safe to run against tenants who've partially seeded curves manually. Audit envelope on the daemon path uses a synthetic `system@market-data-service` actor email so `feedback_audit_actor_email`'s never-null contract holds.

**2026-08-28 — Phase 1: Java deprecated-subclass shims omitted.** The plan called for `ActuarialReportJob extends ReportJob`, `ActuarialReportJobRepository extends ReportJobRepository`, `ActuarialJobPublisher` delegate, and `ActuarialResultConsumer` stub as `@Deprecated` re-exports to keep old imports resolving. Grep confirmed only internal finance-service files reference these types — there are no cross-service Java consumers. Two R2DBC repositories on the same table (parent + subclass) also risks Spring Data bean ambiguity. I renamed the four classes straight, moved them into `com.medfund.finance.report.*`, and updated every internal caller in the same commit. Kafka-topic dual-write, Python `app.actuarial.events` deprecation shim, Angular `ActuarialJobPollingService` alias, and the gateway `/api/v1/reports/actuarial/jobs/*` route alias all stay — those cross service boundaries and provide real roll-out safety. `Phase 23 §1` (delete Java re-exports) becomes a no-op accordingly.
